# Tandem Agent Notes

All substantive Tandem repo guidance lives in the environment-specific context files: `context.md` for Windows desktop work and `contextL.md` for Ubuntu/Linux/proot work.

- At the start of a session, read `contextL.md` when running from Ubuntu/Linux/proot, or `context.md` when running from Windows.
- If editing package-specific code, also check the nearest nested `AGENTS.md` for that package.
- Keep this file as a small pointer only so it does not duplicate context guidance.
