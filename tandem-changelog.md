# Tandem Mobile App Changelog

The Android (`packages/android`) and iOS (`packages/ios`) app packages are Tandem-owned product code, inherited from the discontinued Whispercode project (Whispercode is no longer maintained; Tandem carries its mobile apps forward). Upstream OpenCode has no mobile app packages, so the apps are not upstream divergence and are not tracked in `log.md` — but every upstream-shared file the apps depend on (the platform contract, shared mobile UI behavior, rebranding seams) **is** still inventoried there. Read `log.md` before changing shared web-UI or server code the apps rely on.

This file has two parts: a current-state baseline of the apps, and a dated history (newest first). New app work appends dated entries to History; when a change alters the apps' current shape, also update the matching Baseline bullet.

## Baseline — current state (recorded 2026-07-25)

### Android app (`packages/android`)

- The Android app workspace package: Vite entry and shared-app mount through mobile platform providers. Files: `packages/android/package.json`, `packages/android/index.html`, `packages/android/vite.config.ts`, `packages/android/tsconfig.json`, `packages/android/src/entry-android.tsx`.
- Android Tauri mobile configuration, Rust app shell, capabilities, and mobile bridge plugin. Files: `packages/android/src-tauri/Cargo.toml`, `packages/android/src-tauri/Cargo.lock`, `packages/android/src-tauri/build.rs`, `packages/android/src-tauri/tauri.conf.json`, `packages/android/src-tauri/capabilities/default.json`, `packages/android/src-tauri/src/*.rs`, `packages/android/src-tauri/mobile-bridge/**`.
- The Android Kotlin mobile bridge plugin used by Tauri commands and permissions. Files: `packages/android/src-tauri/mobile-bridge/android/src/main/java/MobileBridgePlugin.kt`, `packages/android/src-tauri/mobile-bridge/android/**`.
- Android bridge, platform storage, default-server persistence, credential persistence, external links (including direct `taobao://` item links), in-app notifications, haptics, share, resume events, and mobile platform marking. Files: `packages/android/src/bridge.ts`, `packages/android/src/storage.ts`, `packages/android/src/entry-android.tsx`, `packages/android/src-tauri/capabilities/default.json`.
- Stabilized Android keyboard resizing and viewport behavior: the WebView root follows `visualViewport`, generated `adjustResize`/`MainActivity`/Gradle daemon patches are applied before Tauri commands, scroll-bottom state refreshes when the viewport changes, and native Android page pinch zoom is disabled. The shared-file side (`packages/ui/src/hooks/create-auto-scroll.tsx`) is documented in `log.md`. Files: `packages/android/index.html`, `packages/android/src/entry-android.tsx`, `packages/android/package.json`, `packages/android/patch-android-generated.ts`, `packages/android/src-tauri/templates/MainActivity.kt`.
- Persisted mobile page zoom: Android CSS-root zoom with viewport-height and safe-area compensation, iOS `WKWebView.pageZoom`, and Android hardware volume-key zoom stepping. The shared settings/platform-contract side (`settings.tsx`, `platform.tsx`, `settings-general.tsx`) is documented in `log.md`. Files: `packages/android/index.html`, `packages/android/src/entry-android.tsx`, `packages/android/src-tauri/templates/MainActivity.kt`, `packages/ios/src/entry-ios.tsx`, `packages/ios/OpenCode/Bridge/PlatformBridge.swift`.
- Android first-run onboarding with setup instructions, manual URL entry, optional display name/Basic auth credentials, and `/global/health` then `/health` checks. Files: `packages/android/src/onboarding.tsx`, `packages/android/src/entry-android.tsx`.
- Android has no voice input: the Whispercode-era voice bridge (recording commands, SpeechRecognizer stack, `RECORD_AUDIO` permission, recognition-service `<queries>`, voice overlay) was removed, so the Android platform object omits `startVoiceInput`/`stopVoiceInput`/`voiceStatus` and the shared prompt mic button never renders there; the mobile-bridge plugin now only provides listeners, LAN scan, and share. External keyboard speech-to-text is used instead. Files: `packages/android/src/entry-android.tsx`, `packages/android/src/bridge.ts`, `packages/android/src-tauri/mobile-bridge/*`.
- Android build/install helpers, including dependency-free launcher icon generation and optimized, release-signed side-by-side Y700 variant builds that restore generated metadata, save full logs, support one-time overwrite migration from old debug signatures, and explicitly return after a successful install. Files: `packages/android/build-and-install.sh`, `packages/android/install-y700-variant.ts`, `packages/android/generate-icons.py`.
- Generated Android release-signing patching so release builds use ignored local `packages/android/release.keystore` and `packages/android/keystore.properties` files outside generated Tauri output, and preserved LAN HTTP access for release APKs by keeping generated `usesCleartextTraffic` enabled. Files: `packages/android/patch-android-generated.ts`, `ANDROID_BUILD.md`.
- Soft-keyboard autocorrect/suggestions are **enabled** (stock behavior). An in-app IME override that disabled them (so the server-side prompt corrector saw raw text) was added 2026-06-08 and reverted 2026-06-09 — see History.

### Branding, identity, and docs

- `ANDROID_BUILD.md` (repo root) carries Android release/build guidance and generated/signing artifact caveats.
- Brands Android/iOS native display labels, titles, permissions, and onboarding screens as Tandem while keeping storage keys, bridge events, and default Basic auth username compatible. Sets the Android application id to `app.liddokun.tandem` (own install/signing identity, no longer the WhisperCode namespace); the iOS bundle id is unchanged. Files: `packages/android/src-tauri/tauri.conf.json`, `packages/android/patch-android-generated.ts`, `packages/android/src/onboarding.tsx`, `packages/ios/index.html`, `packages/ios/OpenCode/Info.plist`, `packages/ios/src/onboarding.tsx`.
- Android launcher icon: a white "T" monogram (with depth shadow) on the brand teal→sky→violet gradient — a gradient `<shape>` drawable background for adaptive icons plus gradient-baked legacy/round PNGs. Files: `packages/android/generate-icons.py`.
- Mobile onboarding frames connecting to a Tandem _or_ OpenCode server: dual-brand welcome/install copy, the Tandem logo mark on the welcome screen, install links to both the Tandem GitHub releases page and `opencode.ai`, and both `tandem web`/`opencode web` start commands. Files: `packages/android/src/onboarding.tsx`, `packages/ios/src/onboarding.tsx`.
- Mobile onboarding and LAN scanning prefer Tandem's parallel-install web port `4097`, with native scanners retaining `4096` fallback for opencode-compatible servers (the shared-file side in `legacy-home.tsx` is documented in `log.md`). Files: `packages/android/src/onboarding.tsx`, `packages/android/src-tauri/mobile-bridge/android/src/main/java/MobileBridgePlugin.kt`, `packages/ios/src/onboarding.tsx`, `packages/ios/OpenCode/Bridge/NetworkScanBridge.swift`.
- Android side-by-side release variant app labels are branded Tandem while variant package IDs/APK naming stay in the opencode namespace for compatibility. Generated Android patching preserves variant identity while still applying release signing and LAN HTTP support. Files: `packages/android/install-y700-variant.ts`, `packages/android/patch-android-generated.ts`.
- Release and on-tablet build tooling is repo-level (`bun run tandem:release`, `bun run tandem:tablet`, `script/android-signing.ts`, `script/android-toolchain-env.ts`) and inventoried in `log.md` under Repo Metadata And Docs.
