Performs exact string replacements in files.

Usage:
- You must Read the file in this conversation before editing, or the call will fail.
- `oldString` must match the file content exactly, including indentation, and must be unique in the file — otherwise the edit fails. Strip the Read line-number prefix (`N: `) before matching; never include any part of it in `oldString` or `newString`.
- Use `replaceAll` to replace every occurrence instead (useful for renaming a string across the file).
