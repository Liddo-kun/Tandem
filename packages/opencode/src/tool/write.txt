Writes a file to the local filesystem, overwriting if one exists.

Usage:
- If the file exists, you MUST Read it first or the call will fail. For partial changes, prefer Edit.
- ALWAYS prefer editing existing files in the codebase; only create new files when required.
- NEVER proactively create documentation files (*.md) or README files. Only create documentation files if explicitly requested by the User.
- Only use emojis in files if the user explicitly requests it.
